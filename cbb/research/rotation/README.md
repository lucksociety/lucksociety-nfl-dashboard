# College basketball rotation correction — 2026-11-22

cbb-1.2.0 adds a bounded player-role correction to existing team scoring targets, retaining the current phase/matchup residual sampler. The deployed feature forecasts roles from earlier games only (80% recent three games, 20% last 20 average), uses seven box-stat profiles shrunk by 400 minutes, and fits own/opponent effects. Ridge 100 and coefficients were selected/refit within 2024–25; correction is capped at ±8 points per team. Current roster/verified absence evidence constrains the displayed expected 200-minute rotation separately; it does not change the historically validated unconditioned scoring feature. Missing coverage falls back to the existing team model and is labeled. No betting gates were relaxed.

Final daily-rating comparison uses identical deterministic 4,000-draw simulations and existing error pools. On 6,073 games in 2025–26: team score MAE 8.82649 → 8.79559; margin MAE 10.64782 → 10.61568; total MAE 13.88817 → 13.85737; log loss .537379 → .534809; Brier .182369 → .181434. On 1,056 games in 2026–27: team MAE 10.14769 → 10.07997; margin 14.13690 → 14.05449; total 14.18790 → 14.08358; log loss .445518 → .441808; Brier .145581 → .144436. Gains are small. The source cohort ends before UTC 2026-11-22 and excludes some late Nov. 21 ET games. These are exploratory chronological historical comparisons, not a guarantee of future wins or ROI. Training/selection does not use confirmation-season labels, but architecture choices were reviewed against these periods.

A variant rebuilding the error pool only from post-training corrected games was rejected. Its evidence is retained as cbb-full-simulation.json. The weekly preserved-pool intermediate result is also retained. The final decision is in cbb-daily-simulation.json and ../../data/rotation-confirmation.json. Existing baseline validation reports describe the team model, not this new correction.

Daily learning now joins final scores by frozen team IDs (fixing feed home/away reversals), reports team/margin/total score MAE by model version and correction status, and grades expected minutes against official normalized actual minutes. This prospective evidence must guide subsequent changes.

Reproduction scripts use ROTATION_RESEARCH_ROOT pointing at a workspace with college/, nba-oracle/, downloaded team/player data, cbb-baseline.json and cbb-daily-bases.json. Run rotation_research.py cbb, impact_research.py cbb, then full_simulation.py --preserve --daily. Large downloaded parquets and generated feature tables are intentionally excluded. Daily bases are the existing model fit at each game's pregame ET day cutoff; the weekly historical baseline supplies residual pools. No current-game box statistics enter features.
