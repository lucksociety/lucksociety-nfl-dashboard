How it works. A Python build step runs the v6 pipeline on nflverse play-by-play and exports, for every week, each team's pre-game feature vector (opponent-adjusted pass EPA/dropback, rush EPA/play, points per drive and points per game ratings with 0.90/week decay; starting-QB adjustment; pace; home; rest; league scoring environment) and the walk-forward stacked ridge model fit only on games played before that week. Your browser turns those into expected points, applies the 0.25-pt-per-team home-field shrink and any capped (±4) QB/injury inputs you set, then runs the v6 drive-level Monte Carlo (game-script feedback, 2-pt decisions, pick-sixes, safeties, overtime) in Web Workers.

Reading the picks. Primary = rounded model mean (beat the sim median on error out of sample). Modal = most frequent simulated exact score; any single exact score is only ~0.5–0.9% likely. 80% ranges are the 10th–90th percentiles of the simulations. Same inputs + same seed = same output.

Zero market input. No spreads, totals, moneylines, odds or public picks are loaded at any stage; the build drops every betting column from the schedule file and asserts none survive.
